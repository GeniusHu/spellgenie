# SpellGenie — Free Spelling Test & Dictation Tool

> **Online**: [spellgenie.net](https://spellgenie.net) — free, no sign-up, for grades 1-8.

Auto-generated spelling tests with real sentences: Dolch and sight word lists, spelling bee words by grade, read-aloud dictation mode, and printable worksheets.

## What makes it different

- **Real sentences, not random words** — every spelling word is embedded in an age-appropriate sentence with actual context
- **Read-aloud dictation mode** — plays each word in sequence for classroom or homeschool testing
- **Grade-matched word lists** — Dolch, Fry, sight words, and spelling bee words organized by grade 1-8
- **No account needed** — open the page, pick a list, start testing

## Tech stack

- Vanilla JavaScript with sentence generation engine
- Web Speech API for read-aloud dictation
- Static hosting
